# Сравнение с npm

Проверка выполнена 2 ноября 2026 года на публичном registry.npmjs.org.
Программа получает зависимости самостоятельно через HTTP JSON API.
npm используется только отдельным проверочным скриптом как эталон.

| Корень | Узлы | Рёбра | Версии и рёбра против npm ls --all |
| --- | --- | --- | --- |
| is-odd@3.0.1 | 2 | 1 | Совпали |
| is-even@1.0.0 | 5 | 4 | Совпали |
| ansi-styles@4.3.0 | 3 | 2 | Совпали |

Для каждого пакета рядом сохранены `.mmd`, `.png`, `-npm.txt`
и `-comparison.md`. В отчётах приведены DFS и полный список рёбер.
PNG исключены из git и остаются локальными результатами запуска.

Для повторения из папки пятого этапа:

```sh
python3 -B scripts/compare_npm.py
```

Нужны Python 3.10+, Node.js, npm и интернет. Проверочный скрипт создаёт
временный проект, устанавливает только указанный корневой пакет
с флагами `--ignore-scripts --no-audit --no-fund --omit=dev`, запускает
`npm ls --all` в текстовом и JSON-форматах. Затем сравнивает множества
пар (имя, версия) и направленных рёбер. Скрипты пакетов не запускаются.

`npm ls --all` показывает дерево установки; Mermaid и PNG показывают
направленный граф. Общая пара (имя, версия) отображается одним узлом;
npm может повторять её в нескольких ветвях или помечать deduped.
У npm CLI нет прямого экспорта Mermaid/PNG, поэтому сравнивается
структура дерева `npm ls`, а не внешний вид изображения.
В этих трёх примерах расхождений в версиях и рёбрах не обнаружено.

На других пакетах возможны различия: npm учитывает peer/optional
зависимости, платформу, lock-файл и правила размещения в node_modules.
Анализатор моделирует только обычные dependencies, выбирает наибольшую
версию по каждому ребру и не воспроизводит всю процедуру установки.
При малой максимальной глубине граф намеренно обрезается.

Исходные форматы:
[Registry API](https://github.com/npm/registry/blob/main/docs/REGISTRY-API.md),
[package metadata](https://github.com/npm/registry/blob/main/docs/responses/package-metadata.md),
[package.json](https://docs.npmjs.com/cli/v10/configuring-npm/package-json/).
